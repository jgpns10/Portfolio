# Portfólio — João Gabriel

Projeto React + Vite com rotas, animações e layout responsivo.

## Executar

```bash
npm install
npm run dev
```

## Personalizar

Edite `src/data/portfolio.js` para trocar dados pessoais, contatos, skills e os três projetos. Coloque sua foto e imagens dos projetos na pasta `public` e atualize os caminhos no mesmo arquivo.
